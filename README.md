# Data-Analyst-Internship-Task-2

## Objective

The objective of this task was to create meaningful visualizations
and communicate insights through data storytelling.

## Tool Used

- Power BI
- Excel

## Dataset

Superstore Sales Dataset

## Visualizations Created

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Sales Trend
- Sales by Category
- Profit by Category
- Sales by Region
- Interactive Category Filter
- Interactive Region Filter

## Deliverables

- Power BI dashboard
- Dashboard screenshot
- PDF report

## Conclusion

The dashboard provides an interactive overview of sales,
profitability, category performance and regional trends.
